# PawLink Landing Page

Landing page para validar el interés de potenciales usuarios de PawLink mediante una campaña de Facebook y un formulario de registro.

## Archivos
- `index.html`: estructura de la landing.
- `styles.css`: estilos responsive.
- `script.js`: validación y confirmación del formulario.
- `assets/pawlink-background.png`: imagen de fondo.

## Importante
Actualmente el formulario valida los campos y muestra una confirmación en el navegador, pero **no almacena los datos en una base de datos**. Antes de usar la landing en una campaña real, se debe conectar el formulario a un backend o servicio de almacenamiento de leads.
